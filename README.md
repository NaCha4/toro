# 토로의 방

제공된 `toro-inoue/source/Toro Inoue.zip`의 모델과 얼굴 텍스처를 사용하는 정적 3D 뷰어입니다. 플레이 영상의 다다미 방을 3D로 재현했습니다. 왼쪽 창가에는 다리 달린 브라운관 TV가 있고, 뒷벽을 따라 올리브색 서랍장, 짙은 목재 장, 은색 오디오, 스피커, 빨간 가방과 냉장고가 놓여 있습니다. 오른쪽에는 미닫이문과 바구니가 있습니다.

## 실행

Node.js 22 이상을 사용합니다.

```sh
npm ci
npm run dev
```

로컬 주소는 `http://127.0.0.1:4173/toro/`입니다. 수정 후 `npm run build`를 다시 실행하고 브라우저를 새로고침합니다.

Chrome 개발자 도구의 기기 툴바에서 이 로컬 주소를 열면 전체화면 버튼을 누르지 않아도 가로·세로 창에서 모바일 화면을 조작할 수 있습니다. 게시된 사이트에서는 주소 끝에 `?preview=1`을 붙이면 같은 미리보기가 열립니다.

## 빌드와 게시

```sh
npm run build
npm run preview
```

`scripts/export-model.mjs`는 제공된 `ToroHigh fixed.dae`와 텍스처를 GLB로 변환합니다. 원본의 7개 메시, 18개 뼈대, UV와 16개 표정을 보존합니다. 원본에서 사용하지 않는 정점 색상 속성은 GLB 로딩 시 잘못 적용되지 않도록 제외합니다.

`scripts/build.mjs`는 GitHub Pages용 정적 파일을 `docs/`에 생성합니다. 게시 설정은 `codex/toro-3d` 브랜치의 `/docs` 경로를 사용합니다. 상대 경로로 로딩하므로 `/toro/` 아래에서도 모델과 텍스처가 작동합니다.

## 조작

- 카메라는 방 정면에 고정
- 시작 시 등을 보이는 토로를 터치하면 돌아서 2번 표정으로 손을 흔들며 인사
- 인사를 마치면 1번 표정으로 돌아와 1초 대기한 다음 카메라 앞으로 걸어와 광각 얼굴 클로즈업으로 정지
- 화면이 표시된 상태에서 3초간 기다리면 움직이는 터치 안내 표시
- 키보드로는 모델에 포커스를 두고 Enter 또는 Space로 인사 시작

모바일 진입 대기와 백그라운드에서는 연출 타이머가 진행되지 않습니다. 카메라는 정면 위치를 유지하며 접근 후반부에 화각과 내려다보는 각도를 부드럽게 전환합니다.

클로즈업 상태에서 3초간 입력이 없으면 머리를 쓰다듬는 손동작 안내를 표시합니다. 머리 위에서 누른 채 좌우·상하로 움직이면 4번 표정으로 바뀌고, 목과 고개가 입력 방향을 크게 따라가며 방향을 바꿀 때 탄성 있게 흔들립니다. 마우스 드래그와 터치를 지원합니다.

머리를 한 번 쓰다듬고 손을 떼면 토로가 바로 1번 표정으로 돌아와 냉장고 쪽으로 몸을 돌립니다. 냉장고로 걸어가면서 카메라도 방 정면 구도로 복귀합니다. 문을 열고 리본 선물상자를 꺼내 양손으로 들고 돌아와 내밀며, 내미는 순간부터 12번 표정을 사용합니다.

선물상자 클로즈업에서 상자를 터치하면 뚜껑·리본과 색종이가 튀어 오르고 수능 케이크와 응원카드가 나옵니다. 카드와 케이크에는 “수능 대박”만 표시합니다. 키보드로는 선물상자 화면에서 Enter 또는 Space로 열 수 있습니다.

응원카드와 케이크가 모두 나온 뒤 3초가 지나면 토로가 케이크와 카드가 든 상자를 냉장고 선반에 다시 넣습니다. 손을 뗀 뒤 냉장고 문을 닫습니다. 토로가 돌아오는 동안 카메라도 방 가운데로 이동합니다. 토로가 화면 중앙에 서면 왼쪽에 「ことばをおしえる」, 「おどる」, 「おくりもの」가 차례로 나타납니다. 「おどる」를 선택할 때마다 영상의 춤을 한 번 추고 다시 서면 같은 메뉴가 열립니다. 메뉴는 터치, 마우스, 방향키와 Enter로 조작할 수 있습니다.

「おくりもの」를 고르면 바로 사케가 배달됩니다. 토로가 오른쪽 미닫이문을 열고 복도에서 초록색 상자를 받아옵니다. 방 가운데에서 술병과 잔을 꺼내 다섯 번 따라 마시고, 두 손을 모아 인사합니다. 빈 술상을 문밖에 반납하고 돌아오면 다시 같은 메뉴를 사용할 수 있습니다. [참고 영상의 배달 장면](https://www.youtube.com/watch?v=STvPYUBLCzY&t=927s)

인사는 5.8초 동안 준비 동작, 팔 올리기, 손 흔들기, 팔 내리기와 잔동작을 이어갑니다. 비균등 키프레임과 3차 곡선 보간으로 흔드는 폭과 속도가 조금씩 달라집니다. 어깨, 팔꿈치, 손목과 고개에 시간차를 주고 손끝이 입체적인 호를 그리도록 구성했습니다. 고개, 상체, 골반과 양쪽 무릎이 함께 움직이며 발바닥 높이를 계산해 바닥 접촉을 유지합니다. 카메라 앞으로 다가오는 시간은 4.2초이며 양팔과 다리를 교차해 움직입니다.

브라우저에서 모델을 불러올 때 양쪽 손목 보조 관절과 부드러운 스킨 가중치를 추가합니다. 손목을 독립적으로 구부리고 회전시켜 팔꿈치 뒤에 따라오는 동작을 표현합니다.

## 말 가르치기

방 가운데로 돌아온 뒤 첫 메뉴 「ことばをおしえる」를 고릅니다. 말풍선을 누르면 글이 끝까지 나타나고, 다시 누르면 다음 화면으로 넘어갑니다. 포켓스테이션에서는 영문 A–Z 중 한 글자를 고르고 대문자나 소문자를 선택합니다. 본체의 네 방향 버튼과 오른쪽 결정 버튼, 액정 터치, 방향키와 Enter를 사용할 수 있습니다. 액정의 첫 줄을 눌러 키보드로 직접 입력할 수도 있습니다. 위쪽의 점 세 개를 누르면 한 글자 지우기, 입력 결정, 입력 그만두기가 나옵니다.

휴대폰에서는 대화 중 화면을 가볍게 눌러 다음 대사로 넘어갑니다. 대답을 고를 때는 위에 질문이 함께 보이고, 선택지가 많으면 ‘이전’과 ‘다음’으로 넘길 수 있습니다. ‘키보드 입력’을 누르면 휴대폰 자판으로 한글과 영문을 함께 쓸 수 있습니다. 액정 한 줄에는 한글 네 글자 또는 ‘딸기Cake’가 들어갑니다. ‘입력 완료’를 누르면 토로에게 단어를 건넵니다.

토로는 단어의 분류와 플레이어의 취향을 이 브라우저에 기억합니다. 같은 단어를 다시 가르치면 뜻을 확인하거나 고치거나 잊게 할 수 있습니다. 주황색 메뉴가 열렸을 때 토로를 직접 누르면 개인적인 이야기를 하거나 배운 말을 꺼냅니다. 키보드로는 방 화면에 초점을 두고 Enter를 누릅니다.

입력기, 첫 분류 18개, 사람 이름·단체 이름·인사말의 세부 선택지, 호감도 다섯 단계는 초대판 화면을 참고했습니다. 유명인과 장소의 세부 항목, 일부 후속 질문과 교정·회상 대사는 한국어판을 위해 보완했습니다. ## iPhone 12 mini와 전체화면

812×375 CSS 픽셀의 가로 화면을 기준으로 버튼을 낮고 조밀하게 배치하며 노치와 홈 표시줄의 안전 영역을 반영합니다. 화면 높이는 동적 뷰포트를 사용해 Safari 주소창 변화와 회전을 따라갑니다.

가로 전체화면 상태가 아닐 때 전체화면 버튼이 표시됩니다. 지원되는 브라우저에서는 사용자 클릭으로 Fullscreen API를 호출하고, 지원되는 기기에서는 가로 방향 잠금을 요청합니다. 전체화면을 종료하거나 세로로 돌아가면 버튼이 다시 표시됩니다.

모바일에서는 가로 전체화면에 진입하기 전까지 방과 모델을 숨기고 렌더링을 일시 정지합니다. 진입 후에는 조작 UI 없이 방과 토로만 화면 전체에 표시합니다. 전체화면 종료 또는 세로 회전 시 즉시 다시 숨깁니다. 홈 화면 웹 앱의 가로 실행도 전체화면으로 인식합니다. 컴퓨터에서는 창 모드와 전체화면으로 플레이할 수 있습니다.

iPhone Safari는 일반 웹페이지의 Fullscreen API와 강제 방향 전환에 제약이 있어 버튼을 누르면 홈 화면 실행 안내를 표시합니다. Safari의 공유 메뉴에서 홈 화면에 추가하고 웹 앱으로 실행한 후 가로로 돌리면 주소창 없이 이용할 수 있습니다. OS 버전과 회전 잠금 설정의 영향을 받습니다. 앱 매니페스트는 가로 전체화면을 요청하며 별도의 오프라인 캐시는 설치하지 않습니다.

애니메이션은 제공된 뼈대를 이용해 이 뷰어에서 구현했습니다. 모션 감소 설정에서는 각 자세를 정지 상태로 표시합니다.
